Six questions, one file

The record is shaped around the questions I expect people to ask about a release. The people on the left are my guess, not research, which is what the third diagram is about.

Before

What changed and whether it is ready are answered while the release is still a draft, from data Tower already reads.

Frozen

Pipeline runs get pruned and tracking state is swept. The evidence a release shipped with is copied into the record when it is sealed.

After

The outcome and the after-release notes arrive later, as pull requests to the same file, so the story stays in one place.
