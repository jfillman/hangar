Portability · 02 of 06 · The shape

Two contracts, many drivers

The forge and the registry are two independent choices, and today they are welded together: the image path is ghcr.io/<GitHub owner>/<app> and the pull credential is a GitHub token. Hangar owns the two contracts; each vendor is a driver behind one of them.

SCM contract

  • Declarative: Repository, RepositoryFile, Webhook, MergeGate, as scm.hangar.io resources.
  • Imperative: pr open, find, comment, status, contents, compare, token.
  • One Go library behind the provider, the scm CLI and the broker.

Registry contract

Push, pull, digest and cosign already speak plain OCI. Only listing with dates and deleting are vendor APIs, so only those need drivers.

Capability, not the lowest common denominator

A driver declares what it can enforce, such as a required check from one named app. Tower shows the level each app actually has.
