Where GitHub is load-bearing today

GitHub is mostly an accident of where Hangar was built: a literal here, a curl there. In three places it is part of the design: the Crossplane resources that write to repositories, the GitHub App that mints CI tokens, and the annotation Tower uses to decide who owns an app.

Load-bearing

  • RepositoryFile: 70 templates, 64 live, the source of the 2026-09 data loss and rate-limit storms.
  • github.com/project-slug: Tower authorization (ACC-05), approvers, catalog apps.
  • GitHub App tokens: the never-persisted credential the platform is built on.

Mechanical

The owner literal, ghcr.io in onboarding, hardcoded links, the Images tab and the prune call. Each is config or one driver, and none needs a design decision.

Already neutral

Tekton, Pipelines as Code (it speaks GitLab and Bitbucket), Argo CD, ESO, the dockerconfigjson pull secret, cosign and Rekor. They stay as they are.
