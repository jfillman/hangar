Where the policy lives

Architects and security teams own the rules. The platform team owns the code that enforces them. The developer owns a short request, and never has to read either.

Ask

The schema is the first policy. A region that is not on the list is not a value the API will take, so it never reaches a review.

Always

The Composition adds what every service gets whether anyone asked or not. Nobody remembers the tags, because nobody has to.

Never

Admission policies and CI checks are the fence for anything that slips around the API. They fail loudly, with a rule id a person or an agent can read.
