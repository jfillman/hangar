Visual identity — logo concepts for review

Four ways to draw a hangar door.

Same aviation vocabulary as the brand system, four different container languages. Each gives Hangar a primary mark and gives Glidepath, Tower, Airframe, and Apron a sub-mark of their own — related, not identical, so the family reads together on a nav rail, a favicon strip, or a docs cover.

The vocabulary repeats on purpose. Every concept below draws the same five ideas, just in a different container: arch/roofline for Hangar, diagonal + dot for Glidepath's descent, mast + signal arcs for Tower, spar + rivets for Airframe's structure, 2×2 grid for Apron's parking stalls. Color is fixed too: amber for Hangar and Tower (home base, command console — the two that need attention), sky for Glidepath and Airframe (informational, structural), and neutral gray for Apron (ground infrastructure — at rest). That's the existing "calm cockpit" rule from the brand system, just applied to which mark gets which color.

Concept A

Instrument Dial

Every mark is a gauge: a ring of compass ticks, a heading-bug index at twelve o'clock, and a product glyph sitting where the needle would point. Reads as flight instrumentation, not branding.

On the Kubernetes echo — this is the one concept that visually rhymes with a ship's wheel (a circle, radial marks). Kubernetes' name comes from the Greek kybernetes, "helmsman" — the wheel is a literal pilot's wheel. Hangar's whole vocabulary is the aviation-era update of that same idea, so the echo is conceptual before it's visual. The rim deliberately has no spokes crossing it — the wheel's real signature — so it reads as an aircraft gauge, not a nautical wheel. Swap the ring for a plain dot (see Concept D) if you'd rather not gesture at it at all.

Resolved — one mark, two renders

A logo isn't one asset, it's a small set of renderings of the same idea, built for different jobs. The dial you see above — free-floating, no background — is the inline mark: it sits directly on whatever surface it's placed on (a nav rail, a doc page, a card header) and only works where the page controls the background behind it. Anywhere the mark has to be the background — a favicon, a GitHub org avatar, a Backstage catalog tile, an OS dock icon — it needs a fixed fill of its own, or it disappears against a dark tab bar or bleeds into a white one. That's the tile mark below: the identical ring, ticks, and arch glyph, just contained on the same fixed instrument-black square every icon-consuming surface expects. Same logo, two jobs — not a second logo.

Exploring clean vs. instrument

Four points on the same spectrum, all built from the same three parts — rim, heading bug, arch glyph — just adding or removing detail. Everything left of center reads more like a real gauge; everything right of center reads more like a clean modern mark that happens to be circular.

Final pick
Full instrument
8 ticks + heading bug + arch. Reads as a real gauge. Strongest k8s echo.
Quartered
Only N/E/S/W ticks. Half the noise, still legibly a dial.
Quiet
No ticks. Rim + bug + arch. No echo, still has a "pointer."
Minimal
Rim + arch only. Closest to Concept C's restraint, still a circular mark.

Concept B

One architectural container — a rounded-top door — shared by all five marks, with a small chevron mounted at the apex like a beacon light. The most literal reading of "Hangar" as a place, which makes it the most ownable silhouette of the four.

Concept C

Wordmark + Glyph

No container at all — a two-stroke glyph sitting directly beside the condensed wordmark, in the spirit of Stripe or Linear. Every glyph is one or two strokes plus a dot, at a fixed weight, so it survives shrinking better than the other three concepts and pairs cleanly with the wordmark treatment the brand system already uses.

Concept D

Radar Squircle

Rounded-square app-icon badges on a fixed instrument-black fill, so favicons and catalog tiles look identical regardless of which theme the surrounding page is in — the same reason a Slack or VS Code icon never re-themes. The practical pick for anywhere a mark has to be a single square asset.

On the Kubernetes echo — if you want a nod without the compass-ring reading of Concept A, Hangar's mark here is a beacon dot with one sweep arc — a rotating circular instrument, same conceptual family as a helm wheel, framed as an aviation radar scope instead of a nautical one. It's a much quieter reference than A's; drop the arc for a plain dot to skip it entirely.

Studio take

Decided: Concept A, full instrument. All 8 compass ticks, the heading bug, and the arch glyph — the busiest end of the spectrum, and the one that reads most convincingly as real flight instrumentation. B, C, and D stay archived above; the Quartered, Quiet, and Minimal variants stay archived within Concept A as the reduction path, worth revisiting if the mark ever needs to quiet down for a specific surface (a favicon at 16px, say) — but the working primary mark going forward is the full ring.

Keeping every tick also means keeping the Kubernetes echo — that was made with eyes open, not a wash. The inline/tile resolution above and every sub-mark, nav-rail mockup, and texture already shown under Concept A carry forward unchanged.
