# Library

Illustrated reviews, reports and specs, shown on the site at
[hangarplatform.dev/library](https://hangarplatform.dev/library/) beside the diagrams.

Every page here is generated by `tools/library/build.py` (one `r_*.py` module per paper), so they
share one stylesheet (the profile the 2026-09-27 architecture review set) and draw their figures
with the diagram generator's primitives. Don't edit the HTML by hand; edit the module and rebuild.

**Convention:** a new paper is a new `tools/library/r_<slug>.py`, a rebuild, and a new entry in
`web/src/data/library.ts` with its status. Papers that already live in the docs get an entry with
an `href` instead of a page. Reviews are point-in-time records: update the status, not the review.
