# Hangar

Home base for building, releasing, and watching every service you run.

An API-centric, event-driven Internal Developer Platform: Crossplane as the
custom control plane, ArgoCD/GitOps for delivery, Backstage (Tower) as the single
pane of glass, Glidepath as the CI/CD component underneath it, Airframe as the
service catalog that ties them together.

See **[docs/README.md](README.md)** for the full table of contents across every
Hangar-family repo.
